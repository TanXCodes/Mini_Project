# AI-Based Emergency Corridor System for Ambulances (Team Vortex)

AIML mini project, GLA University Mathura.

## Setup
```
pip install -r requirements.txt
streamlit run app/app.py
```

3. Data is synthetic. All settings live in `config.yaml`.
